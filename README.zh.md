# Plain Speak（白話解釋）

一個將複雜術語、縮寫和領域專業詞彙轉化為清晰、經過驗證的白話解釋的 Claude Code Skill。內建反幻覺機制：每個術語都先網路搜尋交叉驗證，再進行說明。

## 功能特色

- 三層分類：常見術語（快速驗證）、專業術語（標準搜尋）、前沿概念（深度搜尋並確認來源）
- 解釋前強制網路搜尋——絕不猜測，永遠附上來源
- 三層解釋架構：一句話版本、日常類比、具體範例
- 根據使用者程度調整深度與類比風格（非技術人員、初級開發者、資深開發者、領域專家）
- 批次模式：同時解釋三個以上術語時，額外提供摘要表格
- 來源優先順序：官方文件 > Wikipedia > 知名技術部落格 > Stack Overflow

## 使用方式

```
/plain-speak
```

觸發詞：「解釋這個詞」、「什麼是 X」、「Y 是什麼意思」、「像我五歲一樣解釋」、「ELI5」、「這是什麼意思」、「幫我解釋」、「白話解釋」、「名詞解釋」，或在閱讀內容時遇到不懂的術語。

## 運作原理

Skill 先判斷術語的領域與複雜度層級，執行 WebSearch 驗證定義，再以三層結構組織說明——一句話版本、日常類比、最小化具體範例。若搜尋結果與訓練知識有衝突，以網路來源為準；若找不到可靠來源，明確說明不確定性，而非憑空捏造。

## 系統需求

- Claude Code CLI
- Claude Code 環境中需有 WebSearch 工具可用
